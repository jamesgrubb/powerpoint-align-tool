Slide Tools support

Align objects and create equal gaps in PowerPoint using keyboard shortcuts or the Slide Tools panel.

Using the tools

Select one object to align it to the slide edges or centre. Select multiple objects to align them relative to their combined bounds. Select at least three objects for equal horizontal or vertical gaps; the outer objects stay in place.

Default shortcuts: use Option (⌥) on Mac or Alt on Windows.
ActionKeys
Left / rightOption or Alt + A / D
Top / bottomOption or Alt + W / S
Horizontal / vertical centresOption or Alt + H / V
Horizontal / vertical equal gapsOption or Alt + Shift + H / V

Use PowerPoint Undo to reverse an operation. If Office asks which action should use a conflicting shortcut, choose Slide Tools to assign it to this add-in.

Requirements

Keyboard shortcuts require Microsoft 365 PowerPoint for Mac 16.105.2 or later; Windows version 2601 (build 19628.20150) or later, or Monthly Enterprise Channel version 2604 (build 19929.20172) or later. The host must support SharedRuntime 1.1. Update PowerPoint if shortcut support is unavailable.

Troubleshooting

If a shortcut opens the panel, check whether the selected objects moved before pressing it again. Keep keyboard focus on the slide canvas when using object shortcuts. Finish editing text before aligning objects.

If the panel reports an unsupported PowerPoint version, update Microsoft 365. Aligning one object to the slide requires PowerPointApi 1.10; other operations require PowerPointApi 1.5. This release supports unrotated objects. Equal spacing requires enough room for non-overlapping gaps.

The app needs an internet connection to load. Workplace administrators may restrict add-ins.
