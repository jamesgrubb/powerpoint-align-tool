Short description:
Align PowerPoint objects and create equal gaps with quick keyboard shortcuts.

Long description:
Slide Tools brings keyboard-driven alignment and equal spacing to PowerPoint. Keep your focus on the slide while arranging objects using easy-to-remember shortcuts.

- Align left, right, top, bottom, or horizontal and vertical centres.
- Select one object to align it to the slide.
- Select multiple objects to align them relative to each other.
- Create equal horizontal or vertical gaps between three or more objects while keeping the outer objects in place.
- Use the visual shortcut map and buttons whenever helpful.

Presentation geometry is processed inside PowerPoint. Slide Tools does not upload presentation contents or include analytics. An internet connection is required to load the add-in.

Compatibility statement must be completed after platform testing. Single-object slide alignment requires PowerPointApi 1.10. This version supports unrotated objects and rejects spacing that would require overlapping gaps. Office may ask you to resolve a shortcut conflict.
