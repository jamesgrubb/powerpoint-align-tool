Install on Mac

Use Microsoft 365 PowerPoint for Mac 16.105.2 or newer. Managed work accounts may require your IT team's approval for add-ins.

  1. Download the XML file above. Keep its .xml extension.
  2. Save your presentations and quit PowerPoint.
  3. In Finder, press ⌘⇧G and open:
    ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  4. Open the wef folder. If it doesn't exist, create a folder named wef here.
  5. Move the downloaded slide-tools.xml file into that folder.
  6. Reopen PowerPoint. Choose Home → Add-ins → Developer Add-ins → Slide Tools. Menu wording may vary.

Open Slide Tools once in each presentation to activate its keyboard shortcuts. If PowerPoint asks which command should use a shortcut, choose Slide Tools for the shortcuts you want.

Install on Windows

This beta uses an Office shared-folder catalog. Use Microsoft 365 PowerPoint desktop version 2601 (build 19628.20150) or later; on Monthly Enterprise Channel, version 2604 (build 19929.20172) or later. If your organisation blocks catalogs or file sharing, ask IT to deploy the XML manifest.

  1. Download slide-tools.xml above into a dedicated folder, such as Documents/SlideToolsCatalog.
  2. In File Explorer, right-click that folder → Properties → Sharing → Share. Share with your own Windows account with Read/Write access. Copy the network path shown, such as \\YOUR-PC\SlideToolsCatalog.
  3. In PowerPoint, open File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs.
  4. Paste the network path into Catalog Url, choose Add catalog, enable Show in Menu, and select OK.
  5. Save your work and restart PowerPoint. Choose Home → Add-ins → Advanced → Shared Folder, select Slide Tools, then Add.

Open Slide Tools in each presentation. Sidebar buttons work independently of shortcut registration; if shortcuts fail, use the buttons.

Update or remove on Windows

To update, replace the XML in your catalog folder and restart PowerPoint. To remove the beta, remove only its XML. If a cached entry remains, follow Microsoft’s Office cache instructions; clearing the cache can affect other sideloaded add-ins.

Give it a quick test

Use a copy of a presentation or a blank test deck.

  1. Select two or more objects. Try ⌥A / D / W / S for left / right / top / bottom, and ⌥H / V for horizontal / vertical centers.
  2. Select three spaced objects and try the equal-gap buttons. The outer objects should stay in place.
  3. Check PowerPoint Undo after each operation. Test shortcuts with the sidebar closed.

Send feedback to the person who invited you: include your PowerPoint version, command, expected result, and actual result. Use a non-confidential example if sharing a screenshot.

Beta limitations

  • Rotated objects are not supported.
  • Slide alignment needs PowerPointApi 1.10; the add-in will explain if your version doesn't support it.
  • Distribution requires enough room for non-overlapping gaps.
  • Shortcut conflicts, text-editing behavior, and Undo still need broader testing.

Data and access

The add-in requests permission to read and edit the open presentation to move selected objects. Its current code does not upload presentation contents or include analytics. Railway hosts the app files and may process ordinary web request metadata; Microsoft provides the Office runtime. This test link is publicly accessible to anyone who has it.

Remove the beta

Quit PowerPoint, remove the Slide Tools XML file from the wef folder above, and reopen PowerPoint. Keep other add-in files in that folder.
